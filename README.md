# nako.bot

Nako's landing page, served by GitHub Pages from this branch at https://nako.bot.

One static file, `index.html`, plus her stickers. `?t=<ms>` freezes the animation at a moment and `?t=end` shows the finished chat.

`install.sh` and `install.ps1` hand off to the installer scripts in [Nako-Agent](https://github.com/QuillDev/Nako-Agent).
